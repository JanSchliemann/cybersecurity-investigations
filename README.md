# Cybersecurity Investigation Portfolio

Hands-on cybersecurity investigation portfolio focused on incident triage, log analysis, threat investigation, and incident response.

This repository contains simulated cybersecurity investigations designed to demonstrate practical security analysis, investigation methodology, and incident response skills.

## Investigation Framework

Each investigation follows a structured process:

1. Detect
2. Triage
3. Investigate
4. Assess Impact
5. Map Findings to MITRE ATT&CK
6. Contain
7. Remediate
8. Document
